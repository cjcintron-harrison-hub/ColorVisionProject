# Color Blindness Color Combination Finder

## Description

**version 1.0**

My program is designed to determine what combination of colors are color blind friendly and to give information about the three different major types of color blindness.


## Developer

Cameryn Cintron-Harrison

## Example

To run the program, give the following commands:

```
g++ --std=c++11 *.cpp -o cvp
./cvp
```
